# Windows how-to (SSM v32)

1. python.org → install → check "Add python.exe to PATH"
2. Unzip project
3. install.bat → wait for OK
4. start-simple.bat
5. Open http://localhost:8501

If streamlit missing: `python -m pip install streamlit` then `python -m streamlit run interface/app.py --server.port 8501`

Optional AI: your OPENAI_API_KEY only; enable AI_ADVISORY in parameters.json
