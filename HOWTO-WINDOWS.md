# Как посмотреть SSM на Windows (просто)

Нужны: компьютер с Windows и интернет.  
Цель: увидеть **графики и таблицу** в браузере.

---

## Шаг 0. Один раз установить Python

1. Откройте браузер → https://www.python.org/downloads/
2. Скачайте **Python 3.11** или **3.12** (кнопка Download).
3. Запустите установщик.
4. **Важно:** внизу окна поставьте галочку  
   **「Add python.exe to PATH」** / «Добавить Python в PATH».
5. Нажмите **Install Now**.
6. Дождитесь конца → Close.

Проверка: нажмите клавишу **Win**, введите `cmd`, Enter. В чёрном окне напишите:

```text
python --version
```

Должно показать, например, `Python 3.12.x`. Если «не найдено» — переустановите Python с галочкой PATH.

---

## Шаг 1. Скачать проект

### Вариант А (проще) — ZIP с GitHub

1. Откройте: https://github.com/BubuRR/sovereign-stress-monitor  
2. Зелёная кнопка **Code** → **Download ZIP**.  
3. Распакуйте ZIP (ПКМ → «Извлечь всё») в папку, например:  
   `C:\Users\ВАШЕ_ИМЯ\Desktop\ssm`

### Вариант B — Git (если установлен)

```text
git clone https://github.com/BubuRR/sovereign-stress-monitor.git
```

---

## Шаг 2. Запуск одной кнопкой

1. Откройте папку проекта (где лежат файлы `start.bat`, `ssm_core.py`, `requirements.txt`).  
2. Найдите файл **`start.bat`**.  
3. **Двойной щелчок** по `start.bat`.  
4. Подождите:
   - установка библиотек (первый раз дольше);
   - строки вроде `[SSM FEED] SMH: LIVE...`;
   - откроется браузер с панелью.

5. Адрес панели: **http://localhost:8501**  
   (если браузер сам не открылся — скопируйте этот адрес в Chrome/Edge).

На панели вы увидите:
- график **Official G vs Ground**;
- график **GAP**;
- таблицу по странам;
- выбор страны → 5 сигналов «земли».

**Остановить:** закройте чёрное окно `start.bat` или нажмите в нём `Ctrl+C`.

---

## Если что-то пошло не так

| Симптом | Что сделать |
|---------|-------------|
| «Python не найден» | Шаг 0, галочка PATH, перезапустить ПК |
| Окно сразу закрылось | ПКМ по `start.bat` → Изменить — в конце есть `pause`; или запускайте из cmd |
| Панель пустая / «Run ssm_core» | В той же папке в cmd: `python ssm_core.py`, потом снова `start.bat` |
| Нет графиков | Обновите страницу http://localhost:8501 (F5) |
| Антивирус ругается | Разрешите Python / папку проекта |

## Без start.bat (вручную в cmd)

1. Win → `cmd` → Enter.  
2. Перейти в папку проекта, например:

```text
cd /d C:\Users\ВАШЕ_ИМЯ\Desktop\ssm\sovereign-stress-monitor-main
```

3. По очереди:

```text
python -m pip install -r requirements.txt
python ssm_core.py
python -m streamlit run interface\app.py --server.port 8501
```

4. Браузер → http://localhost:8501

---

## Что люди проверяют за 2 минуты

1. Есть ли строки `LIVE` для SMH.  
2. У **UA** Ground и S выше, чем у **US**.  
3. Есть ли **GAP** / alarms у напряжённых стран.  

Это и есть смысл прибора — не один «%», а слои рядом.
